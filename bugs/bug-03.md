# BUG-03: «Устгах» товчнууд улаан биш, НОГООН өнгөтэй

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155 (headless, Playwright), Windows 11, 2026-10-18

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Хөтөч дээр http://localhost:3000 нээ.
2. Хүснэгтийн сүүлийн баганын «Устгах» товчнуудын өнгийг хар.
3. Нэмэлт (заавал биш): «Устгах» товч дээр хулганы баруун товч → Inspect → Computed → `background-color`.

Хүлээгдэж байсан: Спецификацийн 6-р дүрэм — аюултай үйлдлийн товч (Устгах) улаан өнгөтэй.

Бодит үр дүн: Бүх «Устгах» товч ногоон — `background-color: rgb(44, 122, 75)` (#2C7A4B), цагаан үсэгтэй. Өөрөөр хэлбэл устгах үйлдэл аюулгүй/эерэг үйлдэл шиг харагдана.

Ноцтой байдал: Minor — спецификацийн шууд зөрчил, ажиллагаанд нөлөөгүй. Гэхдээ эргэж болохгүй үйлдэл (ном шууд устна) эерэг өнгөтэй байх нь санамсаргүй устгах эрсдэлийг нэмнэ.
