# BUG-15: `POST /api/books` хүсэлтийн бие `null` байхад сервер унаж (процесс зогсч) бүх өгөгдөл, хэрэглэгч сална

Орчин: Уншлагын жагсаалт v2.0, curl 8.21 (Git Bash, Windows 11), Node.js v24.16.0, 2026-10-18

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном); нэг терминалд апп ажиллаж байна (терминал A), хүсэлтийг өөр терминалаас илгээнэ (терминал B)

## Дахин гаргах алхам

1. Терминал B-д ажиллуул:

   ```bash
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d 'null' 2>&1 | tee evidence/bug-15-curl.txt
   ```

2. Хариуг хар.
3. Терминал B-д дахин: `curl -i localhost:3000/api/books`.
4. Терминал A (апп ажиллаж байсан)-ыг хар; хөтөч дээр http://localhost:3000-г шинэчил.

Хүлээгдэж байсан: Спецификацийн 8-р дүрэм (буруу биетэй хүсэлтэд 400 алдаа) ба эрүүл ухаан — нэг буруу хүсэлт серверийг унагаж болохгүй; сервер `400` буцаагаад үргэлжлүүлэн ажиллана.

Бодит үр дүн: HTTP хариу ирэхгүй (Windows curl: `curl: (56) Recv failure: Connection was reset`; Linux curl-д ихэвчлэн `curl: (52) Empty reply from server`). Дараагийн хүсэлт `curl: (7) Failed to connect to localhost:3000 ... Could not connect to server`. Терминал A-д node процесс `TypeError: Cannot read properties of null (reading 'title')` алдаагаар дуусч, хөтөч дээр хуудас нээгдэхгүй. Санах ойн бүх өгөгдөл алдагдана; апп-ыг гараар дахин асаах хэрэгтэй. Өөр хачин бие (`"abc"`, `123`, `true`, `false`, `[1,2]`, `{}`) серверийг унагаадаггүй — зөвхөн `null`.

Ноцтой байдал: Critical — нэг энгийн, нэвтрэлтгүй хүсэлт бүхэл аппыг зогсоож (DoS), бүх өгөгдлийг устгана.
