# BUG-05: Footer-ийн «Хуучин хувилбар» линк (`/old`) «Internal Server Error» (HTTP 500) өгдөг

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155 (headless, Playwright), Windows 11, 2026-10-18

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Хөтөч дээр http://localhost:3000 нээ.
2. Хуудасны хамгийн доор зүүн талд байгаа «Хуучин хувилбар» линк дээр дар.
3. Нээгдсэн хуудсыг хар.
4. API түвшинд (терминалд): `curl -i localhost:3000/old`.

Хүлээгдэж байсан: Спецификацийн 8-р дүрэм — бүх хуудас, линк ажиллана. Линк нь хуучин хувилбарын хуудсыг (HTTP 200) нээнэ.

Бодит үр дүн: Хуудсанд зөвхөн «Internal Server Error» гэсэн энгийн текст гарна; `curl -i` → `HTTP/1.1 500 Internal Server Error`. Console-д `Failed to load resource: the server responded with a status of 500`. `/old?v=1`-д ч 500; зөвхөн GET дээр (POST/PUT/DELETE → 404). Хуудсанд буцах линк байхгүй тул хөтчийн «Back» л гарц.

Ноцтой байдал: Major — үндсэн хуудсан дээрх нэг ил линк ажиллахгүй, хэрэглэгчийг алдааны хуудас руу аваачна; спецификацийн шууд зөрчил.
