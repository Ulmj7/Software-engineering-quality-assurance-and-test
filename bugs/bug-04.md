# BUG-04: «Нэмэх» товчны сүүлийн үсэг Кирилл «х» биш Латин «x» байна

Орчин: Уншлагын жагсаалт v2.0, Google Chrome 155 (headless, Playwright), Windows 11, 2026-10-18

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Хөтөч дээр http://localhost:3000 нээ.
2. `F12` → Console табыг нээ.
3. Дараах мөрийг буулгаад Enter дар (нүүр хуудасны эхний товч нь «Нэмэх» товч):

   ```js
   [...document.querySelector('button').textContent].map(c => 'U+' + c.codePointAt(0).toString(16).toUpperCase().padStart(4, '0')).join(' ')
   ```

Хүлээгдэж байсан: Спецификацийн 5-р дүрэм — текстүүд үсгийн алдаагүй. «Нэмэх» гэдэг үг бүхэлдээ Кирилл үсгээс бүтэх ёстой: `U+041D U+044D U+043C U+044D U+0445`.

Бодит үр дүн: `U+041D U+044D U+043C U+044D U+0078` — сүүлийн тэмдэгт нь Латин `x` (U+0078). Дэлгэц дээр «Нэмэх»-тэй ялгагдахгүй харагдана. Хуудасны бусад харагдах текст, placeholder-т Латин/Кирилл холимог үг өөр байхгүй.

Ноцтой байдал: Cosmetic — нүдэнд ил харагдахгүй, ажиллагаанд нөлөөгүй. Гэхдээ текст хайх (Ctrl+F), хуулах, дэлгэц уншигч, мөн «Нэмэх» гэсэн текстээр товч хайдаг автомат тест (Playwright `getByRole('button', { name: 'Нэмэх' })`) энэ товчийг олохгүй.
