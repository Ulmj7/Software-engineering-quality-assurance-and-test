# BUG-14: Буруу JSON биетэй `POST /api/books` хүсэлтэд 400 биш `200 OK {"result":"OK"}` буцаана

Орчин: Уншлагын жагсаалт v2.0, curl 8.21 (Git Bash, Windows 11), 2026-10-18

Урьдчилсан нөхцөл: `node app.js`-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминал нээ (апп `node app.js`-ээр асаалттай, порт 3000).
2. Дараах тушаалыг ажиллуул:

   ```bash
   mkdir -p evidence
   curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{bad json' 2>&1 | tee evidence/bug-14-curl.txt
   ```

3. Хариуны эхний мөр (статус код) болон биеийг хар.
4. Нэмэлт: `curl -i localhost:3000/api/books` — жагсаалтад шинэ ном нэмэгдээгүй (3 ном хэвээр).

Хүлээгдэж байсан: Спецификацийн 8-р дүрэм — буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана (`HTTP/1.1 400 Bad Request`, алдааны тайлбартай).

Бодит үр дүн: `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}` — хүсэлтийг амжилттай гэж мэдэгдэх боловч юу ч хадгалагдаагүй. Ижил үр дүнтэй хувилбарууд: `-d 'буруу оролт'` (Content-Type заагаагүй), таслагдсан JSON `{"title":"x"`.

Ноцтой байдал: Major — спецификацийн шууд зөрчил; API клиент өөрийн буруу хүсэлтийг мэдэхгүй, «амжилттай» гэж итгээд өгөгдөл чимээгүй алдагдана.
