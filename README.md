## Дүгнэлт (Хэсэг E)

**1. Аль аялал хамгийн үр дүнтэй байв?** Тоогоор Supermodel хамгийн үр дүнтэй: session-ийн эхний 8 минутад хуудсыг нүдээр хараад, линк болон урт оролт туршаад 6 согог (BUG-01, 02, 03, 04, 05, 11) олов. Fed-Ex 4 согог (BUG-08, 09, 10, 12) олсон бөгөөд Network tab-аар UI-ийн дууддаг `/api/stats` ба `?q=` хайлтыг илрүүлж BUG-01, BUG-09-ийг API түвшинд ч баталгаажуулсан; Couch Potato 2 согог (BUG-06, 07) олов. Saboteur хамгийн цөөн (BUG-14, 15, 16) боловч хамгийн ноцтойг — нэг `null` хүсэлтээр сервер унадаг Critical BUG-15-ыг — олсон.

**2. Charter-аас гадуур санамсаргүй юу олдов? Юу шалгагдаагүй үлдэв?** Charter-д байгаагүй `/api/stats` endpoint, `&`-ийн давхар escape (BUG-12), сервер унасан үеийн UI-ийн дуугүй алдаа (BUG-16), Латин «x»-тэй товч (BUG-04) санамсаргүйгээр олдсон. Шалгагдаагүй үлдсэн нь: Firefox/Safari (Playwright-ийн Firefox суугаагүй), бодит гар утас, дэлгэц уншигч, аюулгүй байдал (header, нэвтрэлт), олон цагийн ачаалал, мөн `/old` хуудас 500 өгдөг тул түүний агуулга. Дараагийн session-ийн charter: «Firefox ба гар утсан дээр, хүртээмж (a11y) болон аюулгүй байдлын чиглэлээр, `/api/stats`-ийг Saboteur аялалаар судлах».

**3. Лаб 1-ийн Playwright автомат тестээр аль нь баригдах, аль нь зөвхөн хүний нүдээр олдох байсан бэ?** Автомат тест нь урьдчилан бичсэн assertion-аар л шалгадаг тул оракул нь спецификацид тодорхой согог — BUG-01 (тоолуур = мөр), 05 (линкийн статус), 06, 07, 08, 09, 10, 14 (статус 400) — энгийн `expect`-ээр баригдах байсан; BUG-15 зэрэг «ер бусын оролт»-ыг тест бичигч санаж бичсэн тохиолдолд л. Харин ногоон өнгө (BUG-03), урт текстээр хүснэгт эвдрэх (BUG-11), `&amp;` харагдах (BUG-12), «1,999» формат (BUG-02)-ыг тусгайлан assertion бичихгүй бол автомат тест анзааралгүй өнгөрнө — нүдээр харахад шууд мэдрэгдэнэ. Сонирхолтой нь Латин «x» (BUG-04) хүний нүдэнд огт харагдахгүй боловч `getByRole('button', { name: 'Нэмэх' })` нь товчийг олохгүй (шалгасан: Кирилл нэртэй locator 0 үр дүн) тул автомат тест үүнийг санамсаргүйгээр барих байсан.
